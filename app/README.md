# Lauco Experience — Web App Demo

Demo mobile-first e installabile come Progressive Web App, disponibile nella cartella `/app`.

## Funzioni

- home editoriale e azioni rapide;
- ricerca e filtri dei percorsi;
- dettaglio itinerario con distanza, tempo, dislivello e difficoltà;
- mappa topografica dimostrativa e geolocalizzazione del browser;
- preferiti e mappe offline persistenti tramite `localStorage`;
- modulo di segnalazione dimostrativo;
- service worker per la cache dell'app shell;
- layout responsive per smartphone, tablet e desktop.

## Apertura

Servire la root del progetto via HTTP/HTTPS e aprire `/app/`.

I dati dei percorsi sono dimostrativi. La demo non scrive nel database del CMS: preferiti, download e segnalazioni restano nel browser.
